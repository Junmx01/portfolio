# 关于我

我做的事情只有一件：把脆弱、低效、依赖人工记忆的内部流程，变成更稳定、可复用、可扩展的系统。

不是为了自动化而自动化——而是因为那些每周重复三次的手工操作、那些"只有某人知道怎么做"的隐性步骤、那些一旦有人请假就会出错的流程，本来不应该存在。

## 我解决了什么

- 把每次耗时 1–2 小时的员工数据核对，压缩到 30 秒以内
- 用三个按钮替代完整的合同处理流程：生成 PDF、起草邮件、归档导出
- 搭建 Python + API 管道，每天自动检测出勤异常并生成报告
- 开发内部工具库，让非技术同事也能一键运行浏览器自动化
- 构建 Power BI 仪表盘，把分散的 HR 数据变成实时可读的运营视图

## 我的工作方式

自动化之前先看流程。很多问题不是缺工具，是流程本身有漏洞——例外情况没有处理路径，审批节点不清晰，数据格式靠口头约定维持。

我先把这些理清楚，再决定哪里值得自动化、哪里应该保留人工判断。结果是更稳定的系统，而不只是更快的脚本。
