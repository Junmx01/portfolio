# Problem

HR data was spread across Cezanne, Excel files, and the internal web portal.

There was no centralized view for key metrics such as active headcount, absences, or contract expirations without exporting data manually.

# Solution

A Power BI dashboard is being developed to consolidate the main HR metrics into a single interactive visual panel.

The current prototype works with local data. The next step is direct integration with the Cezanne API so the dashboard can refresh in real time without manual exports.

# Current Status

Functional local prototype completed. API integration is planned next.
