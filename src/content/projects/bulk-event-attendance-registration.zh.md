# 背景问题

每次活动结束后，纸质签到名单都要逐人逐项手动录入公司网页系统。

如果有 40 名参与者，整个过程通常要 2 到 3 小时，而且姓名录入错误也很常见。

# 解决方案

纸质数据只需要在 Excel 中录入一次。随后由 VBA 脚本整理结构，再由 Python 脚本打开门户网站，按顺序自动填写每位参与者的信息。

这个流程具有很强的扩展性：无论是 40 人还是 400 人，操作者的工作量都几乎一样。

# 结果

- 40 人活动的录入时间：从 2 到 3 小时缩短到约 30 分钟
- 手工录入错误：消除
- 可扩展性提升：执行时间不再依赖人工逐项输入
- 数据入口唯一：只需维护最初的 Excel 文件
