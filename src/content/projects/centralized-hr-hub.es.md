# Problema

Las tareas diarias de RRHH requerian moverse constantemente entre el portal web de la empresa, Outlook y Excel para operaciones que deberian poder realizarse desde un solo lugar.

Este cambio continuo de contexto consumia tiempo y aumentaba el riesgo de perder informacion.

# Solucion

Se esta desarrollando una aplicacion que agrega en una unica interfaz los datos del portal web corporativo y los correos de Outlook relevantes para RRHH.

El usuario puede consultar y operar sin salir de la aplicacion. La estructura base esta desarrollada y funcional.

# Estado Actual

Estructura base completada. En desarrollo activo.
