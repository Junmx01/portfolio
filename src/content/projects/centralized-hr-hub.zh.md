# 背景问题

HR 日常工作需要频繁在公司门户、Outlook 和 Excel 之间切换，而这些操作本应能在一个统一界面内完成。

持续切换上下文不仅耗时，也增加了遗漏信息的风险。

# 解决方案

我正在开发一套 Python 应用，把公司门户中的关键数据和 Outlook 里与 HR 相关的邮件整合到一个界面中。

用户无需离开应用即可查询和操作。目前基础结构已经搭建完成，并且可以运行。

基础结构已完成，项目仍在持续开发中。
