# 背景问题

HR 数据分散在 Cezanne、Excel 文件和内部网页系统中。

团队缺少一个统一视图来查看关键指标，例如在职人数、缺勤情况和合同到期，而不必每次都手动导出数据。

# 解决方案

我正在开发一个 Power BI 仪表板，把核心 HR 指标整合进一个交互式可视化面板。

当前原型基于本地数据运行。下一步计划直接接入 Cezanne API，使数据能够实时刷新，彻底去掉手工导出步骤。

# 当前状态

本地数据原型已可运行。API 集成处于规划中。
