# 背景问题

缺勤识别脚本本身效果不错，但仍然需要技术方式执行，团队其他成员无法直接使用。

部门需要一套任何人都能通过浏览器查看的方案，同时数据应当保持可持续访问，而不是依赖手动运行脚本。

# 解决方案

我开发了一套 Web 应用，把脚本逻辑封装进浏览器可访问的可视化界面。

它可以先在本地环境中测试，也已经为部署到公司内部服务器做好准备。访问通过与 API 绑定的凭证控制，确保只有授权用户可以查看数据。

# 结果

- 整个团队都可使用，无需执行脚本
- 任意内部设备都能实时查看出勤数据
- 已准备好部署到企业服务器
- 具备基于 API 的访问控制
