# Problem

Daily HR work required constant movement between the company web portal, Outlook, and Excel for tasks that should ideally be handled in one place.

This context switching consumed time and increased the risk of missing information.

# Solution

A Python application is being developed to bring together relevant web-portal data and Outlook information in one operational interface.

Users can review and act without leaving the application. The core structure is already built and functional.

# Current Status

Base structure completed. Active development continues.
