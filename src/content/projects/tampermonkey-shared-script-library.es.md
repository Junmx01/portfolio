# Problema

Algunas automatizaciones desarrolladas para uso propio podian beneficiar a todo el equipo, pero requerian conocimientos tecnicos para ejecutarse.

No existia una forma sencilla de compartir estas herramientas con companeros sin perfil tecnico.

# Solucion

Se empaquetaron las automatizaciones mas utiles como scripts de usuario Tampermonkey, distribuibles mediante un enlace de instalacion.

Una vez instalados, los scripts se activan automaticamente en las paginas correspondientes y anaden funcionalidades como descargas automaticas y acciones de un clic directamente en la interfaz del navegador, sin que el usuario tenga que hacer nada adicional.

# Resultados

- automatizaciones disponibles para todo el equipo, sin barreras tecnicas
- distribucion instantanea mediante enlace
- interfaz nativa del navegador, sin software adicional
