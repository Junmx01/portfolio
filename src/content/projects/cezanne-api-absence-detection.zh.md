# 背景问题

部门原本没有一套系统化方法来识别未提前报备的缺勤情况。

如果要靠人工检查所有员工的打卡记录，就必须逐个进入系统核对，因此几乎不可能作为日常流程执行。

# 解决方案

我开发了一个 Python 脚本，连接 Cezanne 的 REST API，提取当天打卡记录，并与在职员工名单进行自动比对。

没有打卡记录的员工会被自动识别出来，结果会整理成结构化报告，不需要人工逐项检查。

# 结果

- 为部门新增了一项此前不存在的能力
- 每日缺勤识别实现自动化，无需人工复核
- 报告数秒内生成，可立即用于后续处理
- 为后续的出勤控制 Web 应用打下基础
