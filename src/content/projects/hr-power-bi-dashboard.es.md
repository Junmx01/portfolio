# Problema

Los datos de RRHH estaban dispersos entre el sistema Cezanne, archivos Excel y el portal web.

No existia una vista centralizada que permitiera al equipo consultar metricas clave sin exportar datos manualmente.

# Solucion

Se esta desarrollando un dashboard en Power BI que consolida las metricas principales de RRHH en un panel visual interactivo.

El prototipo actual funciona con datos locales. El siguiente paso es conectarlo directamente a la API de Cezanne para que los datos se actualicen en tiempo real, eliminando cualquier exportacion manual.

# Estado Actual

Prototipo funcional con datos locales. Integracion con API en planificacion.
