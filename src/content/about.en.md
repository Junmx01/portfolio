# About Me

I turn fragile, manual, memory-dependent internal processes into systems that are stable, reusable, and built to scale.

Not automation for its own sake — but because workflows that break when someone is out, steps that only one person knows how to run, and tasks repeated three times a week by hand should not exist.

## What I've Solved

- Compressed a 1–2 hour employee data reconciliation into under 30 seconds
- Replaced a full contract-processing flow with three buttons: PDF generation, email drafting, archive export
- Built a Python + API pipeline that detects attendance gaps daily and delivers a ready-to-use report
- Developed an internal script library so non-technical teammates can run browser automations with one click
- Designed a Power BI dashboard that turns scattered HR data into a real-time operational view

## How I Work

I look at the process before touching the tooling. Most problems are not missing a tool — the process itself has gaps: no path for exceptions, unclear approval points, data formats held together by verbal agreement.

I map those out first, then decide what to automate and where human judgment should stay. The result is a more reliable system, not just a faster script.

## Let's Work Together

If you have a workflow that costs your team the same hours every week, or a process that depends on one person's memory at a critical step — I'd be glad to dig into it with you.
